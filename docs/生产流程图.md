# ArknightsAvatar 生产流程图（拉取资源 → 最终 avatar 资源）

> 来源：逐模块阅读 `src/arknightsavatar/`（fetch / unpack / classify / match / detect / extract
> 及 `sources/`、`unpack/` 子模块，外加编排入口 `run / pull / produce / derive-model /
> sync-cache` 与统一入口 `cli`）。
> 阈值均为代码内实际默认值（`src/arknightsavatar/*.py` 常量）。
> 识别数据统一在 `data/recognition/`（不带 `_` 前缀），与原始 avatar、提取 avatar、
> 统计列表一起由独立 GitHub 数据仓库承载（`arknightsavatar sync-cache` 增量提交）。

## 0.1 编排入口

| 入口 | 步骤链 |
| --- | --- |
| `arknightsavatar run` | fetch → unpack → classify → match → extract → export-webp → npc-json（`--from`/`--until` 选段） |
| `arknightsavatar pull` | fetch（`--with-apk` 可选追加 pull-apk） |
| `arknightsavatar produce` | classify → match → extract → export-webp → npc-json（离线，不触设备） |
| `arknightsavatar derive-model` | 读 `data/recognition/face_detect_matched.json` → 最小二乘拟合 → `data/recognition/derive/{model.json, derive_coords.json, stats.json, compare/}` |
| `arknightsavatar sync-cache` | 本地数据目录 → `data_cache` 工作副本（clone/pull）→ git add + 有变化才 commit |

统一入口 `arknightsavatar <子命令>` 分发到上述编排入口与 12 个单工具；编排入口
进程内依次调用各工具的 `main(argv)`，失败中止并指明步骤，统计写入 `data/stats/`。

## 1. 拉取资源（fetch）— `arknightsavatar-fetch`

模块：`src/arknightsavatar/fetch.py`、`sources/base.py`、`sources/apk.py`、
`sources/apk_adb.py`、`sources/adb.py`、`sources/device.py`、`manifest.py`

```mermaid
flowchart TD
    Start(["arknightsavatar-fetch"]) --> Cfg["加载配置<br/>CLI 参数 > ARKNIGHTSAVATAR_* 环境变量 > config.toml"]
    Cfg --> Src{"选择资源源 --source"}
    Src -->|"apk"| APK["ApkAdbSource<br/>设备已安装 APK<br/>unzip -p 按需解压"]
    Src -->|"local-apk"| LOCAL["ApkSource<br/>assets/AB/Android 解包目录<br/>（config.toml: apk.dir）"]
    Src -->|"adb 默认"| ADB["AdbSource<br/>adb_shell 连接设备<br/>Bundles 目录（official/bilibili）"]
    APK --> Cat["遍历资源<br/>characters / avatars"]
    LOCAL --> Cat
    ADB --> Cat
    Cat --> List["list_files 列出 .ab 文件及大小"]
    List --> Loop{"逐个文件处理"}
    Loop --> Chk{"manifest 已记录<br/>且 size/sha256 相同<br/>且本地文件已存在？"}
    Chk -->|"是"| Skip["skipped 跳过"]
    Chk -->|"否"| Pull["拉取/拷贝到 name.part 临时文件"]
    Pull --> Hash["计算 sha256"]
    Hash --> OK{"成功且大小非 0？"}
    OK -->|"是"| Move["os.replace 原子替换<br/>→ data/raw/<分类>/<name>.ab<br/>更新 manifest.json 记录"]
    OK -->|"否"| Fail["记录到 data/raw/_failed.json"]
    Move --> Save["每 50 个增量落盘<br/>manifest.json + _failed.json"]
    Skip --> Save
    Fail --> Save
    Save --> Next{"还有文件？"}
    Next -->|"是"| Loop
    Next -->|"否"| Done(["结束：data/raw/*.ab + manifest.json"])
```

产物：`data/raw/<分类>/<name>.ab`、`data/raw/manifest.json`
（`{game_version, updated_at, files:{rel:{size,sha256,source}}}`）、`data/raw/_failed.json`。

## 2. 解包（unpack）— `arknightsavatar-unpack`

模块：`src/arknightsavatar/unpack/unpacker.py`、`unpack/ab.py`、`unpack/ak.py`

```mermaid
flowchart TD
    Start(["arknightsavatar-unpack --category all"]) --> Load["读取 data/raw/manifest.json<br/>按 rel 取得 source_sha256"]
    Load --> Iter["遍历 data/raw/ 每类 *.ab"]
    Iter --> Inc{"data/unpacked/_manifest.json<br/>已记录相同 sha 且 meta 存在？"}
    Inc -->|"是"| Skip["skipped"]
    Inc -->|"否"| Parse["AbParse 解析 AB<br/>（读入内存避免 Windows 文件锁）"]
    Parse --> Patch["安装明日方舟自定义 LZ4 补丁<br/>替换 UnityPy 的 LZHAM 解压（ak.py）"]
    Patch --> Obj["遍历对象：Texture2D / Sprite / MonoBehaviour"]
    Obj --> RGBA["RGB 与 name[alpha] 纹理<br/>合并为全分辨率 RGBA"]
    Obj --> Meta["MonoBehaviour typetree 递归提取<br/>facePos + faceSize → face_groups"]
    RGBA --> Cat2{"分类"}
    Meta --> Cat2
    Cat2 -->|"characters"| Item["data/unpacked/<分类>/<id>/<name>.png<br/>+ meta.json（textures/sprites/face_groups）"]
    Cat2 -->|"avatars"| Ava["仅保留 char_* 且正方形头像<br/>data/unpacked/avatars/<name>.png<br/>bundle 元数据归 avatars/_meta/<bundle>.json"]
    Item --> Upd["更新 _manifest.json<br/>失败记 _failed.json"]
    Ava --> Prune["清理遗留非 char_* / 非正方形 PNG"]
    Prune --> Upd
    Upd --> More{"还有 AB？"}
    More -->|"是"| Iter
    More -->|"否"| Done2(["结束：data/unpacked 全量 PNG + meta"])
```

说明：`meta.json` 中的 `face_groups`（facePos/faceSize 配对）是后面 extract 组合
小尺寸 diff 的关键元数据；`data/unpacked/_manifest.json` 与 `_failed.json` 是解包
簿记，不进 `data/recognition/`。

## 4. 头像匹配（match）— `arknightsavatar-match`

模块：`src/arknightsavatar/match.py`

```mermaid
flowchart TD
    Start(["arknightsavatar-match"]) --> ReadC["读取 data/recognition/characters_classified.json<br/>仅处理 avg_<id>_ / char_<id>_ 角色"]
    ReadC --> Cache{"输出报告已存在？<br/>（非 --force）"}
    Cache -->|"是"| Skip["跳过：不重新匹配<br/>直接结束（--force 强制重跑）"]
    Cache -->|"否"| Cand["候选头像<br/>data/unpacked/avatars/char_<seq>_*<br/>角色名去末尾变体号后按编辑距离升序"]
    Cand --> Prep["底图：灰度 → 缩放到 1024 → 顶部向上扩展 76px<br/>头像：灰度（保持原尺寸）"]
    Prep --> Search["模板匹配 TM_CCOEFF_NORMED + 缩放搜索"]
    Search --> Coarse["最佳阈值低于 confidence-target(0.85)<br/>→ 5px 粗搜；达标后 → 1px 微调"]
    Coarse --> Cross["跨阈值时回查 ±(step-1) 邻域偏移<br/>候选级早停：阈值 > 0.85 即采用并跳过后续候选"]
    Cross --> Best["取阈值最高候选 → 头像包围盒 box"]
    Best --> Norm["box 换算回底图原始像素<br/>+ box_norm（1024 归一化，y 可为负）"]
    Norm --> OutM["输出 data/recognition/avatar_match.json"]
    OutM --> Done(["结束（extract 第 2 档直接复用该报告）"])
    Skip --> Done
```

## 5. 人脸 / 头部识别（detect）— `arknightsavatar-detect` / `arknightsavatar-detect-bases`

模块：`src/arknightsavatar/detect.py`、`detect_bases.py`

```mermaid
flowchart TD
    Start(["arknightsavatar-detect / detect-bases"]) --> Face["anime-face-detector YOLOv3 人脸检测<br/>top-1，检测框×1.1 放大"]
    Face --> Head["imgutils detect_heads 头部检测<br/>top-1"]
    Head --> OutD["face_pos / head_pos + confidence<br/>detect-bases 仅处理匹配 threshold > 0.95 的底图<br/>并输出可视化标注 PNG"]
    OutD --> CacheD["缓存 data/recognition/face_head_detect.json<br/>（extract 复用，避免重复推理）"]

```

detect 报告默认 `data/recognition/face_detect.json`；detect-bases 报告默认
`data/recognition/face_detect_matched.json`（同时是 `arknightsavatar derive-model`
的输入），标注图在 `data/recognition/face_detect_vis/`。

## 6. 头像提取（extract）— `arknightsavatar-extract`（核心生产步骤）

模块：`src/arknightsavatar/extract.py`

### 6.1 主流程

```mermaid
flowchart TD
    Start(["arknightsavatar-extract"]) --> Load["读取输入<br/>分类报告 data/recognition/characters_classified.json（必需）<br/>匹配报告 data/recognition/avatar_match.json（可选）<br/>手动 data/recognition/avatar_manual.json（可选）<br/>推导模型 data/recognition/derive/model.json<br/>缓存 data/recognition/face_head_detect.json / avatar_extract_cache.json"]
    Load --> Chars["遍历角色（--character / --limit 过滤）"]
    Chars --> Meta["读取角色 meta.json 的 face_groups<br/>加载 alpha.png（可选，alpha 通道贴图）"]
    Meta --> BaseLoop{"遍历底图 base"}
    BaseLoop --> BOut{"data/export/<角色>/<base>.png 已存在<br/>且非 --force？"}
    BOut -->|"是"| BSkip["base skipped<br/>读回已有头像参与去重"]
    BOut -->|"否"| BoxResolve["三档解析裁切框 resolve_base_box"]
    BoxResolve --> Done3(["完成单个角色 → 下一个角色"])
    Done3 --> Chars
```

### 6.2 裁切框三档解析（resolve_base_box）

```mermaid
flowchart TD
    Tier1{"第 1 档：手动框？<br/>data/recognition/avatar_manual.json 键 “角色/图片”"}
    Tier1 -->|"是"| M["method=manual, confidence=1.0<br/>直接采用"]
    Tier1 -->|"否"| Tier2{"第 2 档：匹配报告<br/>threshold > 0.8 且 box 有效？"}
    Tier2 -->|"是"| T["method=match<br/>直接采用匹配框"]
    Tier2 -->|"否"| Fd["face+head 识别<br/>（走 face_head_detect.json 缓存）"]
    Tier2 -. "报告缺失或 --force-match" .-> Inline["内联调用 match_base 重算匹配"]
    Inline --> Tier2
    Fd --> Tier3{"第 3 档：模型推导<br/>face > 0.8 且 head > 0.7？"}
    Tier3 -->|"是"| D["data/recognition/derive/model.json coef 推导正方形框<br/>[cx,cy,s] = coef @ features<br/>method=derive, confidence=face 置信度"]
    Tier3 -->|"否"| NB["base no_box（不提取）"]
    M --> DoneB["返回 (box, method, confidence)"]
    T --> DoneB
    D --> DoneB
    NB --> DoneB
```

### 6.3 提取 + 多 base 去重 + 差分提取

```mermaid
flowchart TD
    Box["base 裁切框（6.2 得到）"] --> Crop["extract_avatar<br/>按框裁切（越界透明填充）→ 180×180 LANCZOS"]
    Crop --> Dedup{"多 base 去重 _dedup_bases<br/>两两透明合成灰度相关相似度"}
    Dedup -->|"相似度 > 0.98"| Drop["丢弃低置信 base（档位 manual>match>derive<br/>同档比分数，再按文件名稳定排序）<br/>其 base 与 diff 不写文件，标记 dropped"]
    Dedup -->|"否则"| Keep["保留全部 base"]
    Keep --> SaveB["保存 data/export/<角色>/<base>.png"]
    Drop --> DiffLoop{"遍历该 base 的差分 diff"}
    SaveB --> DiffLoop
    DiffLoop --> IsAlpha{"文件名是 alpha.png？"}
    IsAlpha -->|"是"| SkipA["跳过（不参与提取、不计入报告）"]
    IsAlpha -->|"否"| DOut{"输出已存在且非 --force？"}
    DOut -->|"是"| DSkip["diff skipped"]
    DOut -->|"否"| Compose["compose_diff 组合<br/>同尺寸 diff 直接用<br/>小尺寸按 faceSize 缩放后贴到 facePos<br/>A 通道取 base（有 alpha.png 时面部区域优先用其灰度）"]
    Compose --> DMan{"手动框？"}
    DMan -->|"是"| DBoxM["method=manual"]
    DMan -->|"否"| IoU["在 base 裁切框（脸部范围）内<br/>比较 alpha 不透明掩码 IoU"]

    Special -->|"否"| Reuse["复用 base 的 box / method / confidence<br/>special=false"]
    Special -->|"是"| SDet["对组合图重新 face+head 识别<br/>（缓存）"]
    SDet --> SDer{"face>0.8 且 head>0.7？"}
    SDer -->|"是"| DBoxD["推导框 method=derive<br/>special=true"]
    SDer -->|"否"| DNB["diff no_box"]
    DBoxM --> DCrop["extract_avatar 裁切 180×180"]
    Reuse --> DCrop
    DBoxD --> DCrop
    DCrop --> DSave["保存 data/export/<角色>/<diff>.png"]
    DSave --> DNext{"还有 diff？"}
    DNext -->|"是"| DiffLoop
    DNext -->|"否"| BNext{"还有 base？"}
    BNext -->|"是"| BaseLoop
    BNext -->|"否"| Cache["缓存增量落盘（每 50 次 + 结束）<br/>face/head 识别缓存<br/>base 相似度 / diff 决策缓存"]
    Cache --> Rep["输出报告 data/recognition/avatar_extract.json<br/>每 base/diff: {status, method, confidence, box, avatar_file, special, detect_cache_hit}<br/>stats 汇总 ok/skipped/dropped/no_box/failed 与缓存命中"]
    Rep --> DoneE(["结束"])
```

## 10. 关键阈值（代码实际默认值）

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
